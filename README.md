# 🛒 Product Listing Web App

A responsive product listing and detail page built using the FakeStore API. This app showcases products in a clean grid layout with detailed views, making it ideal for eCommerce concepts.

---

##  How to Install & Run the Project

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/product-listing-app.git
   cd product-listing-app

2. Install dependencies
   npm install
   
3. Run the development server
   npm run dev

# Data Fetching Strategy
Data is fetched client-side using the useEffect hook and fetch API.

Justification: Since the product data is public and doesn’t require authentication, client-side fetching ensures fast loading and dynamic updates without over-complicating the architecture.

# Styling Method
The project uses Tailwind CSS for utility-first, responsive, and maintainable styling.

Ensures a clean, consistent layout across components

Grid-based layout used for product cards

Responsive design optimized for mobile, tablet, and desktop

# Bonus Features
✅ Responsive Layout: Adapts seamlessly to all screen sizes
